# Security policy

Rivo is pre-release software and is not ready to host sensitive or production workloads.

Please do not publish exploitable security vulnerabilities in a public issue. Until a dedicated private reporting channel is configured, contact the maintainer through the GitHub profile associated with this repository and avoid including exploit details in public comments.

Security-sensitive areas include authentication, authorization, uploads, storage paths, moderation permissions, payment flows, and report-abuse prevention.
